# دليل نشر تطبيق Nutritionist Fatma Ali مجانًا

## الملفات
- `index.html`: التطبيق كامل.
- `manifest.webmanifest` ومجلد `icons`: عشان يتثبت على الموبايل.
- `sw.js`: يخلي التطبيق يفتح من غير إنترنت بعد أول فتح (الصفحة نفسها فقط).

## النشر المجاني على GitHub Pages
1. اعملي حساب مجاني على github.com.
2. اضغطي New repository، واختاري اسم (مثلًا `fatma-nutrition`)، واجعليه Public.
3. اضغطي "uploading an existing file" وارفعي كل الملفات اللي في الـ ZIP بعد فك الضغط.
4. من Settings ثم Pages: اختاري Branch: main ومجلد root ثم Save.
5. بعد دقيقة يظهر الرابط (https://اسمك.github.io/fatma-nutrition/). افتحيه من الموبايل.
6. للتثبيت: في أندرويد (Chrome) اضغطي "تثبيت التطبيق"، وفي آيفون (Safari) اضغطي مشاركة ثم "إضافة إلى الشاشة الرئيسية".

## مهم تعرفيه
- **قسم ملفات الحالات والتنبيهات (قسم المالك):** شغال في النسخة المنشورة على Claude فقط. على GitHub Pages مش هيظهر، لأنه محتاج قاعدة بيانات وصلاحيات مالك. بيانات الحالات متتخزنش هناك لأنها بيانات حساسة ومش لازم تكون مكشوفة.
- **بيانات العملاء (الوزن، اليوميات، التقارير، التحديات):** محفوظة على جهاز كل عميل. فيه زر "نسخة احتياطية من بياناتي" في قسم رحلتي الصحية للنسخ والاسترجاع.
- **المزامنة بين الأجهزة وحسابات العملاء والدفع والإشعارات:** محتاجة خدمة خلفية (Backend) آمنة، ومش موجودة في النسخة المجانية.
- النسخة دي بتفتح من غير إنترنت لكن الخطوط وأزرار واتساب والتقويم محتاجة إنترنت.
- لتحديث التطبيق ارفعي `index.html` الجديد مكان القديم، وغيري `CACHE = "fatma-nutrition-v2"` في `sw.js` إلى `v3` وهكذا.

- في آخر الصفحة قسم "⚙️ أدوات التطبيق": زر تنزيل نسخة احتياطية كملف، واستعادتها من ملف، وزر تثبيت التطبيق (بيظهر لما المتصفح يدعمه). ده بيشتغل على الرابط المنشور.
